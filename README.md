## 51taoli 是什么？

51taoli 是一个**只读的市场与套利情报平台**。它将交易所官方或经验证的只读数据，整理为可追溯的跨市场观察，帮助用户了解：

- 跨所 FF / SF / FS 路线的方向性理论价差；
- 资金费、标记价、指数价与原生溢价等不同市场事实；
- 已验证范围内的公告、充提与借贷情报；
- 加密货币与 TradFi 产品目录及其严格身份匹配后的理论观察；
- 平台精选策略的规则、状态、真实观察和历史摘要。

平台当前的只读行情范围包括 Binance、OKX、Bybit、Bitget、Gate、Hyperliquid 与 Aster。不同交易所、市场类型和数据族的实际可用性，以页面数据状态、来源状态及当时运行结果为准；这不代表已覆盖各交易所全部产品。

## 核心原则

1. **只读，不代客交易**：当前公共产品不连接用户交易所账户，不下单、不转账、不提现，也不托管资产。
2. **零假数据**：生产页面不使用模拟行情、伪造机会、补零或插值来填补缺失数据。
3. **事实与结论分层**：理论价差、可执行差价、风险调整后的净边际是不同概念，不能互相替代。
4. **身份和时间优先**：同名代码不自动等于同一资产；数据来源时间、产品身份和报价方向不成立时，应当显示“暂无”或排除路线。
5. **不承诺收益**：大价差不等于可成交利润，真实交易还可能受到深度、手续费、滑点、借贷、清算、资金费和市场变化影响。
