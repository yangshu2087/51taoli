## 三个简单但容易被跳过的检查

1. **方向对不对？** 做多腿该看 `ask`，做空腿该看 `bid`；不要拿中间价、标记价或最后成交价替代。
2. **两条腿真的是同一件东西吗？** 同名 ticker、相近价格或同一计价币都不够。产品类型、单位、合约地址/网络或发行人也要核对。
3. **缺的东西有没有被诚实地留空？** 指定金额下的深度、真实手续费、退出盘口、借贷成本和额度缺失时，不能从理论价差直接推净收益。

- 不连接你的交易所账户，不读取余额/仓位，不要求 API Key；
- 不承诺“无风险”“保证收益”或“一键套利”；
- 不用模拟行情、插值、零值或虚构路线把生产页面塞满。
