# 51taoli

> **全市场套利信息平台**  
> 跨平台、跨品种、全市场套利信息平台

51taoli 是一个**只读的跨市场套利情报平台**。它将官方或经验证的只读市场事实，整理为有来源、有时间、有身份边界的市场观察，帮助用户研究价差、资金费、指数和相关市场条件。

> **先说清楚：**理论价差不是可成交收益；没有足够事实时，51taoli 显示「暂无」，而不是补一个看似合理的数字。

## 你可以用 51taoli 做什么

- 查看跨所 **FF / SF / FS** 路线的方向性理论开差与当前市场事实；
- 对照买一/卖一、资金费、标记价、指数价、时间和来源健康状态；
- 浏览已核验范围内的公告、充提、借贷和 TradFi 官方产品目录；
- 研究平台发布、带版本和状态的精选策略；
- 通过官网、官方社群和公告频道获取已核验的产品信息。

## 不能把它当成什么

51taoli 当前不是：

- 自动下单、跟单、代客交易或资产托管服务；
- 用户交易所账户连接、资金划转或提现工具；
- 保证收益、无风险套利或“一键套利”承诺；
- 用模拟行情、插值或零值填充的机会榜。

价格差、资金费和历史表现都需要结合深度、实际费率、滑点、借贷、额度、产品规则与市场变化独立判断。

## 我们如何处理数据

51taoli 的公开原则很简单：

1. **来源明确**：优先使用交易所官方公开接口，必要时仅使用平台自有、最小权限的只读凭证补充市场情报；
2. **方向正确**：开仓与清仓使用不同方向的真实买一/卖一，不能混用中间价、标记价或最后成交价；
3. **身份可证**：同名 ticker 不自动视为同一资产；
4. **时间独立**：报价、资金费、指数、公告、借贷等字段保留各自的来源时间；
5. **缺失诚实**：缺少关键证据时保留「暂无/未知」，不补值、不插值、不伪造历史。

详见 [数据原则](docs/DATA-PRINCIPLES.md)。
