# 51taoli

> **看跨市场信息，不用交出交易权限。**

[**打开 51taoli 官网 →**](https://51taoli.com/opportunities)　[**加入官方社群 →**](https://t.me/taoli51)　[**查看公告 →**](https://t.me/news_51taoli)　[**询问机器人 →**](https://t.me/taoli51_bot)

51taoli 是一个只读的跨市场套利情报平台。它把不同交易所和市场里的报价、资金费、指数和辅助信息整理到一起，帮助你判断一条价差值不值得继续研究。

## 你可以用它做什么

- 找到 FF、SF、FS 三类跨市场路线；
- 看清两条腿、买卖方向、开差、资金费和市场上下文；
- 按资产、交易所、市场类型筛选，再进入交易、资金费、指数、公告、冲提、借贷或策略页面继续核对。

## 从哪里开始

1. [打开“套利机会”页](https://51taoli.com/opportunities)，挑一条路线；
2. 先看多腿、空腿和报价方向；
3. 再查看资金费、产品身份、深度、费用、退出或借贷等与自己有关的信息。

第一次使用可直接读 [使用路径](docs/USE-51TAOLI.md)。

## 当前覆盖

Binance、OKX、Bybit、Bitget、Gate、Hyperliquid、Aster。

覆盖范围会随市场、产品和数据状态变化；请以官网当时显示为准。

## 使用时记住三件事

- 做多腿看 `ask`，做空腿看 `bid`；
- 同名 ticker 不代表一定是同一资产；
- 理论价差是研究起点，不是最终收益。
