# 常见问题

[**打开官网 →**](https://51taoli.com/opportunities)　[**加入官方社群 →**](https://t.me/taoli51)　[**询问机器人 →**](https://t.me/taoli51_bot)

## 51taoli 是交易所或自动交易机器人吗？

不是。51taoli 用于查看和研究跨市场信息；它不替用户下单，不要求连接交易所账户。

## 为什么需要登录？

登录用于产品身份、会话和页面权限控制，不是交易所授权。

## “套利机会”是否等于最终收益？

不是。理论价差只是研究起点。深度、实际费用、滑点、资金费、借贷、退出条件和市场变化都会影响结果。

## 为什么有些内容显示「暂无」？

当前来源、报价、资产身份或可比条件不足时，页面会保留「暂无」。

## FF、SF、FS 是什么？

它们是不同的市场路线类型。详见 [核心概念](CONCEPTS.md)。

## 七家交易所是否代表全部交易对都已覆盖？

不是。七家交易所是当前只读行情范围；实际覆盖以官网当时显示为准。

## 策略信号会通过 Telegram 发送吗？

Telegram 机器人用于社群答疑、规则、状态和公告支持。策略通知的实际开放状态，以官网账户页为准。

## 如何反馈数据或产品问题？

通过 [GitHub Issues](https://github.com/yangshu2087/51taoli/issues/new/choose) 或 [官方社群](https://t.me/taoli51) 提供资产、交易所、页面链接、发生时间和复现步骤。

请勿发送密码、私钥、API Key、验证码或 Token。
