# 常见问题（FAQ）

> 本页介绍的是产品边界和常见使用问题。实时数据、功能开放与套餐状态以官网当时展示为准。

## 1. 51taoli 是交易所或自动交易机器人吗？

不是。51taoli 当前是只读市场与套利情报平台：展示可追溯的市场事实和理论观察，帮助用户研究。它不替用户下单、不连接用户交易所账户、不划转或提现资产。

## 2. 页面上的“套利机会”是否等于保证赚钱？

不等于。页面上的开差首先是基于真实方向性买一/卖一计算的**理论价差**。实际能否成交及最终结果还受盘口深度、实际手续费、滑点、资金费、借贷成本、额度、交易规则和市场快速变化影响。

如果执行所需证据不足，平台应显示“暂无”或未知，而不是把理论数字写成净收益。

## 3. 为什么同一资产在不同交易所会有价格差？

不同交易所的参与者、流动性、报价更新节奏、合约规格、计价资产、资金费和风险偏好都可能不同。价格差是市场事实，不自动代表可无风险获利。

## 4. 为什么有时某条数据或机会显示“暂无”？

常见原因包括：官方来源没有提供该字段、报价过期、买卖盘不完整、产品身份无法确认、两边计价/单位不可比较、来源被限流，或平台尚未取得足够真实历史。

“暂无”是诚实的状态，不会用模拟值、零值或插值代替。

## 5. 七家交易所是否意味着覆盖了它们的全部交易对？

不是。七家交易所是当前只读行情范围。实际覆盖受官方目录、产品状态、资产身份、市场类型、来源可用性和当前 canonical 快照约束。不能将其理解为“所有交易所、所有交易对、所有数据项均已覆盖”。

## 6. FF、SF、FS 是什么？

它们是不同的套利路线类型：

- **FF**：合约/永续之间的跨所方向性观察；
- **SF**：现货多、合约空的方向性观察；
- **FS**：合约多、现货空的方向性观察，通常还需要核对借币条件。

它们不是具体的投资策略，也不是交易建议。

## 7. 平台的策略和 FF/SF/FS 有什么区别？

FF/SF/FS 是路线类型。平台策略是独立、带版本的筛选与通知规则，必须有明确的范围、触发条件、时效、冷却和停止条件。观察中的策略可以展示，但不应被表述为已开放订阅或已发送。

## 8. 策略信号通过 Telegram 发送吗？

当前产品合同中的用户策略接收渠道是飞书/Lark；Telegram 官方机器人用于社群答疑、规则、状态与公告运营，不提供用户策略绑定或交易执行功能。

## 9. 为什么官方群机器人不能读取我的普通消息？

官方机器人默认保持 Telegram 隐私模式，只处理明确命令，例如 `/help`、`/faq`、`/rules`、`/status`、`/announcements` 和 `/community`。它不应收集或保存普通群聊内容。

如需帮助，请直接使用命令或在社群中向管理员说明问题。

## 10. 官方机器人或管理员会索取哪些信息？

官方机器人和管理员不应索取密码、助记词、私钥、交易所 API Key、短信/邮箱验证码、Bot Token 或资产转账。任何索取此类信息或要求转账的内容都不属于正常支持流程。

## 11. 如何反馈错误数据或产品问题？

请尽量提供：

1. 资产和交易所；
2. 页面链接或截图；
3. 看到问题的时间与时区；
4. 可复现步骤；
5. 是否持续出现。

可通过官方社群或本仓库的 GitHub Issues 提交。请先移除所有账户、订单、地址与密钥等敏感信息。

## 12. 资料库中的内容是否代表实时生产状态？

不一定。该仓库发布产品说明、FAQ 和经核验的公开信息；实时行情、系统可用性、功能开关和数据覆盖必须以官网页面、来源状态及当时生产验证为准。
