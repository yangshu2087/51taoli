# 常见问题

[**打开官网 →**](https://51taoli.com/opportunities)　[**加入官方社群 →**](https://t.me/taoli51)　[**询问官方小助手 →**](https://t.me/taoli51_bot)

## 51taoli 是交易所或自动交易机器人吗？

不是。51taoli 是只读信息平台，不替用户下单、划转或提现。

## 需要把交易所 API Key 交给 51taoli 吗？

不需要。当前公开产品不会要求交易授权、划转授权或提现授权。任何在社群、机器人或 GitHub 中索要私钥、API Secret、验证码或 Token 的行为都不应继续。

## 为什么需要 Google 登录？

登录用于识别 51taoli 账户、会话、订阅版本和个人设置，不是交易所授权。

## 页面上的正开差就是收益吗？

不是。它先表示方向正确的理论报价距离。实际结果还会受到深度、滑点、交易费、资金费、借贷、充提、市场时段和退出条件影响。

## FF、SF、FS、SS、TF、FT、TT 是什么？

它们是七类路线。第一位字母是做多腿，第二位是做空腿：`S` 为加密现货、`F` 为衍生品、`T` 为 TradFi/RWA。详见 [核心概念](CONCEPTS.md)。

## 为什么有些内容显示「暂无」？

这通常表示来源没有返回、数据过期、产品身份未确认、单位不可比或真实历史尚未积累。「暂无」不等于 0。

## 七家交易所是否代表所有交易对都已覆盖？

不是。它们是当前只读行情来源；实际产品、交易对和辅助字段以官网当时显示为准。

## TradFi/RWA 路线是真实股票交易吗？

页面展示的是交易所提供的 TradFi/RWA 产品及其市场身份信息。它不自动等同于你在证券账户中持有或交易底层股票；需要继续核对产品规格、发行人、交易时段、单位和相关市场规则。

## 监控和策略有什么区别？

监控盯住一个明确对象与条件；策略是一套完整的筛选规则。两者都只产生信息或提醒，不会执行交易。

## 哪些策略已经开放？

当前 S01、S02 已开放，其余策略处于验证中或开发中。状态可能变化，请以 [策略页面](https://51taoli.com/playbook) 为准。

## 通知会发到 Telegram 吗？

当前策略与监控通知使用账户中配置的飞书地址。Telegram 官方小助手用于社群答疑、命令帮助和公告入口。

## Telegram 机器人能做什么？

[@taoli51_bot](https://t.me/taoli51_bot) 提供快速上手、核心概念、数据说明、常见问题、策略与订阅、安全核验、服务状态和官方入口。群内只响应显式命令，不读取普通聊天，也不是自由对话 AI 或交易机器人。

## 订阅价格和额度在哪里看？

请查看 [订阅页面](https://51taoli.com/subscription)。页面会根据当前账户显示版本、额度、价格或支付状态。

## 如何反馈数据问题？

通过 [GitHub Issues](https://github.com/yangshu2087/51taoli/issues/new/choose) 或 [官方社群](https://t.me/taoli51) 提供：

- 资产或产品名称；
- 交易所和路线；
- 页面链接；
- 发生时间与时区；
- 复现步骤；
- 已脱敏截图。

请勿提交账户、订单、地址、密码、私钥、API Key、验证码或 Token。
