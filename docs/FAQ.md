# 常见问题（FAQ）

> 先用再读也可以：[**打开官网看一条机会 →**](https://51taoli.com/opportunities)　[**加入官方群 →**](https://t.me/taoli51)　[**问 @taoli51_bot →**](https://t.me/taoli51_bot)

这里解释产品边界和常见用法。实时行情、功能开放、套餐状态和数据可用性，以官网当时展示和来源状态为准。

## 产品与数据

### 1. 51taoli 是交易所或自动交易机器人吗？

不是。51taoli 当前是只读市场与套利情报平台：展示可追溯的市场事实和理论观察。它不替你下单、不连你的交易所账户、不划转或提现资产。

### 2. 页面出现“套利机会”，是不是等于能赚钱？

不是。开差先是按真实方向性买一/卖一得到的理论观察。能否实际成交、最后是赚是亏，还要看深度、实际费率、滑点、资金费、借贷成本、额度、交易规则和市场变化。

想把这件事看明白，读 [理论价差、可执行差价与净边际的区别](CONCEPTS.md#三个数字别混成一个)。

### 3. 为什么同一资产在不同交易所会有价格差？

参与者、流动性、报价节奏、合约规格、计价资产、资金费和风险偏好都不同。价格差是市场事实，不自动等于“无风险获利”。

### 4. 为什么某条数据或机会显示「暂无」？

可能是官方来源没提供、报价过期、买卖盘不完整、身份无法确认、单位不可比、接口限流，或历史还没积累。正确做法是留「暂无」，而不是补零、补中间价或插值。

### 5. 七家交易所，是不是代表每一家所有交易对都覆盖了？

不是。七家交易所表示当前只读行情范围。实际覆盖还受官方目录、产品状态、市场类型、资产身份、来源状态和当前运行快照影响。

### 6. FF、SF、FS 分别是什么？

它们是三种市场路线：FF 是合约/永续之间的跨所观察；SF 是现货多、合约空；FS 是合约多、现货空，通常还要核对借币条件。详见 [核心概念](CONCEPTS.md)。

### 7. 为什么同名 ticker 也可能不能配对？

同名 ticker 可能是不同链、不同合约、不同发行人、不同单位或不同产品类型。51taoli 不会只因名称或价格接近就把它们当成同一个资产；证明不了时，会限制结论或保留「暂无」。

### 8. 我第一次应该怎么用？

先去 [套利机会页](https://51taoli.com/opportunities)，挑一个资产或路线。确认两条腿、开差的 BBO 方向和来源时间；再按需要看资金费、指数、产品目录、公告、冲提或借贷。缺的实际费率、深度、退出或借币条件，也应写进你的结论。完整步骤见 [第一次怎么用](USE-51TAOLI.md)。

## 策略与账号

### 9. 策略和 FF/SF/FS 有什么区别？

FF/SF/FS 是路线类型；平台策略是独立、带版本的筛选与通知规则，需要明确范围、触发、时效、冷却和停止条件。策略不是交易授权，也不是收益承诺。

### 10. 免费、专业版和专业版+有什么区别？

当前产品合同中，Free 用户登录后可查看首页、交易、资金费并浏览策略；Pro 解锁更多只读研究信息并可订阅最多 3 条策略；Pro+ 可订阅最多 20 条策略。价格、付款入口和当前开放状态请以官网账户与订阅页为准。

### 11. 策略信号会通过 Telegram 发送吗？

Telegram 官方机器人用于社群答疑、规则、状态和公告支持。用户策略接收渠道与 Telegram 社群机器人是独立能力，具体开放状态以官网账户页为准。

### 12. 为什么需要登录？

登录用于建立 51taoli 的产品身份和会话，并执行页面与策略权限控制。它不是交易所授权，不绑定你的资产，也不读取交易所余额或仓位。

## 社群与支持

### 13. 为什么官方群机器人不能读取我的普通消息？

官方机器人默认保持 Telegram 隐私模式，只处理明确命令，例如 `/help`、`/faq`、`/rules`、`/status`、`/announcements` 和 `/community`。它不收集或保存普通群聊内容。

### 14. 官方机器人或管理员会索取什么信息？

正常支持不会索取密码、助记词、私钥、交易所 API Key、短信/邮箱验证码、Bot Token 或转账。任何索取这些信息或要求转账的内容，都不属于正常支持流程。

### 15. 怎么提交数据或产品问题？

通过官方社群或 GitHub Issues 提供：资产、交易所、页面链接或截图、发生时间和时区、问题描述和复现步骤。提交前移除账户、订单、地址、密钥、验证码和 Token。
