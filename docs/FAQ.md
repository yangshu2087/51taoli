# 常见问题（FAQ）

> 本页说明产品边界与常见使用问题。实时行情、功能开放、套餐状态和数据可用性，以官网当时展示及来源状态为准。

## 产品与数据

### 1. 51taoli 是交易所或自动交易机器人吗？

不是。51taoli 当前是只读市场与套利情报平台，展示可追溯的市场事实和理论观察。它不替用户下单、不连接用户交易所账户、不划转或提现资产。

### 2. “套利机会”是否等于保证赚钱？

不等于。开差首先是按真实方向性买一/卖一得出的理论观察。能否实际成交及最终结果还受到深度、实际费率、滑点、资金费、借贷成本、额度、交易规则和市场变化影响。

请先阅读 [理论价差、可执行差价与净边际的区别](CONCEPTS.md#三种不能混为一谈的数字)。

### 3. 为什么同一资产在不同交易所会有价格差？

交易所的参与者、流动性、报价节奏、合约规格、计价资产、资金费和风险偏好不同。价格差是市场事实，不自动代表可无风险获利。

### 4. 为什么某条数据或机会显示“暂无”？

可能是官方来源未提供、报价过期、买卖盘不完整、产品身份无法确认、两边计价/单位不可比较、接口限流，或历史尚未积累。正确的处理是保留“暂无”，而不是补零、补中间价或插值。

### 5. 七家交易所是否代表覆盖它们的全部交易对？

不是。七家交易所表示当前只读行情范围。实际覆盖受官方目录、产品状态、市场类型、资产身份、来源状态与当前运行快照约束；不能理解为所有产品和所有数据项均已覆盖。

### 6. FF、SF、FS 分别是什么？

它们是三种市场路线类型：FF 是合约/永续之间的跨所观察；SF 是现货多、合约空；FS 是合约多、现货空，通常还要核对借币条件。详见 [核心概念](CONCEPTS.md)。

### 7. 为什么同名 ticker 也可能不能配对？

同名 ticker 可能对应不同链、不同合约、不同发行人、不同单位或不同产品类型。51taoli 不会只按名称或价格近似把它们视作同一资产；无法证明时会限制结论或保留“暂无”。

## 策略与账号

### 8. 策略和 FF/SF/FS 有什么区别？

FF/SF/FS 是路线类型；平台策略是独立、带版本的筛选与通知规则，必须有明确范围、触发、时效、冷却和停止条件。策略不是交易授权，也不是收益承诺。

### 9. 策略信号通过 Telegram 发送吗？

Telegram 官方机器人用于社群答疑、规则、状态和公告支持。用户策略接收渠道与 Telegram 社群机器人是独立能力，具体开放状态以官网账户页为准。

### 10. 为什么需要登录？

登录用于建立 51taoli 的产品身份和会话，并执行页面与策略权限控制。登录本身不是交易所授权、账户绑定或资产同步。

## 社群与支持

### 11. 为什么官方群机器人不能读取我的普通消息？

官方机器人默认保持 Telegram 隐私模式，只处理明确命令，例如 `/help`、`/faq`、`/rules`、`/status`、`/announcements` 和 `/community`。它不应收集或保存普通群聊内容。

### 12. 官方机器人或管理员会索取哪些信息？

正常支持流程不会索取密码、助记词、私钥、交易所 API Key、短信/邮箱验证码、Bot Token 或转账。任何索取此类信息或要求转账的内容都不属于正常支持流程。

### 13. 如何提交数据或产品问题？

请通过官方社群或 GitHub Issues 提供：资产、交易所、页面链接或截图、发生时间和时区、问题描述及复现步骤。提交前请移除账户、订单、地址、密钥、验证码和 Token 等敏感信息。
