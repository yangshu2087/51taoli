# 从一条机会开始：研究路径

> 这是信息阅读路径，不是交易操作指南。51taoli 当前只提供只读市场情报，不替用户下单或管理资产。

## 1. 从首页识别研究对象

进入 [官网](https://51taoli.com) 的「套利机会」页后，先选择资产或路线类型。首页用于回答：**现在有哪些经过当前数据条件筛选出的跨市场观察？**

此时看到的是当前市场事实形成的路线，不应立即把正开差理解为利润。

## 2. 看清两条腿和开差口径

对一条路线，先核对：

- 做多与做空分别在哪个市场、哪个交易所；
- 多腿是否使用 `ask`、空腿是否使用 `bid`；
- 资产与产品类型是否可比；
- 数据来源时间是否足以支持“当前”判断。

FF、SF、FS 的差异见 [核心概念](CONCEPTS.md)。

## 3. 把开差与清差分开

开差描述当前理论入场观察；清差/清仓成本描述同一真实快照中的反向退出 BBO。两者不能用一个数代替，也不能用开差倍率估算退出成本。

## 4. 补齐市场上下文

按研究需要查看：

- **资金费**：原始费率、原始周期、已结算历史和方向现金流；
- **指数**：指数价格、标记价、指数偏离和原生溢价；
- **公告 / 冲提 / 借贷**：每项事实的来源、范围和更新时间；
- **产品目录**：尤其是 TradFi 产品的官方身份、产品族和单位。

这些字段独立变化，不能因为其中一个值更新就假设其他值也更新。

## 5. 将“缺证据”当作结论的一部分

如果实际费率、指定金额下的深度、完整退出盘口、借币利率或额度等关键事实缺失，正确结论就是：**当前不能从理论开差推出净收益。**

此时页面显示「暂无/未知」不是信息失败，而是在避免不成立的结论。

## 6. 再查看历史和策略

历史只使用持续真实采集的点；缺失不插值、不回填。策略则是独立、带状态和版本的筛选规则，历史表现、当前机会和策略通知都不能取代用户自己的判断。
