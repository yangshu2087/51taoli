# 怎样读一条路线

[**打开机会总览 →**](https://51taoli.com/opportunities)

## 第一步：确认两条腿

先看路线代码，再确认做多腿和做空腿分别属于哪个交易所、哪个市场。第一位字母是做多腿，第二位是做空腿。

例如：`TF` 表示 TradFi/RWA 产品做多，衍生品做空。

## 第二步：确认报价方向

进入时，做多腿看可买入的 `ask`，做空腿看可卖出的 `bid`。不要用两个最新成交价直接代替方向性报价。

## 第三步：把开差和清差分开看

开差描述当前进入两条腿的理论距离；清差描述按相反方向退出时的理论结果。两者的报价方向不同。

## 第四步：补齐可执行条件

根据路线检查与你有关的条件：

- 下单金额对应的盘口深度和滑点；
- 两边交易费与资金费；
- 现货做空所需的借贷利率、额度和期限；
- 充值、提现、网络与市场时段；
- TradFi/RWA 产品身份、规格、单位和汇率口径；
- 退出条件与可能的再扩大风险。

这些信息分布在交易、资金费、指数、公告、充提和借贷页面。

## 第五步：只在证据足够时继续

如果关键字段显示「暂无」、时间不同步、身份不明确或单位不可比，应先停止推断。正开差也不自动等于可成交利润。
