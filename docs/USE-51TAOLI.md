# 怎样读一条路线

[**打开“套利机会”页 →**](https://51taoli.com/opportunities)

## 1. 先看两条腿

选中资产或路线后，先确认多腿和空腿分别在哪个交易所、属于什么市场。FF、SF、FS 的区别见 [核心概念](CONCEPTS.md)。

## 2. 再看报价方向

做多腿使用 `ask`，做空腿使用 `bid`。页面上的开差描述的是这两个方向性报价之间的理论距离。

## 3. 补齐与你有关的条件

根据路线，再看资金费、产品身份、单位、盘口深度、实际费用、退出条件以及借贷利率或额度。相关信息分布在交易、资金费、指数、公告、冲提和借贷页面。

## 4. 再作自己的判断

正开差值得继续研究，但不自动等于最终收益。缺少关键数据时，先保留问题或到 [官方社群](https://t.me/taoli51) 讨论。
