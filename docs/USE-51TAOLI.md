# 第一次怎么用：从一条机会开始

> 这是**读市场信息**的路径，不是交易操作指南。51taoli 当前只提供只读情报，不下单、不管资产，也不连接交易所账户。

[**现在打开“套利机会”页 →**](https://51taoli.com/opportunities)　[**不确定术语？先看 FF / SF / FS →**](CONCEPTS.md)

## 用五步读完一条路线

### 1. 先挑一个你能看懂的对象

在官网「套利机会」页选一个资产或路线类型。别急着找最大的百分比；先问自己：**这两条腿各是什么市场、在哪家交易所？**

### 2. 看多空方向，而不是只看绿色数字

一条路线至少要看清：

- 做多腿在哪里、做空腿在哪里；
- 多腿取的是 `ask`，空腿取的是 `bid`；
- 产品类型、单位和资产身份能不能比较；
- 两边的数据时间是否足够接近，支持“这是现在的情况”。

FF、SF、FS 的直观解释在 [核心概念](CONCEPTS.md)。

### 3. 把“开差”和“怎么退出”拆开想

开差说的是当前理论入场观察；退出时方向反过来，看到的买一/卖一也会变。不要拿开差乘个倍数，就当成退出成本或最终结果。

### 4. 看会改变结论的上下文

按需要打开对应页面：

- **资金费**：交易所原始费率、原始周期、已结算记录和现金流方向；
- **指数**：指数价、标记价、指数偏离和原生溢价；
- **公告 / 冲提 / 借贷**：来源、范围、更新时间、费用、限额或额度；
- **产品目录**：尤其是 TradFi 的正式身份、产品族和单位。

这些项目不是一个大而全的分数。每一项都有自己的来源和更新时间。

### 5. 把缺失信息也写进你的结论

指定金额下的深度、真实手续费、完整退出盘口、借币利率或可用额度缺失时，正确结论是：**现在只能看到理论差，不能推出净收益。**

页面里的「暂无 / 未知」不是产品在敷衍，而是在拒绝把不确定性藏起来。

## 然后再看历史和策略

历史只来自持续真实采集的点；没有采到就不插值、不回填。策略则是独立的筛选与通知规则，有版本和状态。它们可以帮助研究，但不会代替你的判断或授权交易。
