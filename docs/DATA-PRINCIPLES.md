# 数据说明

[**查看官网当前结果 →**](https://51taoli.com/opportunities)

## 1. 页面只展示真实来源返回的事实

生产页面不使用模拟机会、补造历史或合成兜底行。来源没有给出可靠结果时，页面显示「暂无」、空状态或不可用状态。

## 2. 不同字段有不同时间

报价、资金费、标记价、指数价、公告、充提和借贷不是同时更新的。读一条路线时，应同时看：

- 字段来源；
- 更新时间或数据年龄；
- 结算周期；
- 页面是否仍在加载；
- 两条腿是否处在可比较的市场时段。

## 3. 同名不一定是同一个产品

ticker 相同、价格接近或计价币相同，都不足以证明产品可比。跨市场比较还需要核对：

- 现货、衍生品或 TradFi/RWA 类型；
- 正式代码、合约规格和单位；
- 网络或合约地址；
- 发行人、底层资产和交易时段；
- 币种和必要的汇率口径。

身份未确认时，不应为了凑出路线而强行匹配。

## 4. 「暂无」不是 0

「暂无」可能表示来源未提供、请求失败、报价过期、身份不明、单位不可比或真实历史尚未积累。它不能被解释为费率为 0、风险为 0 或条件满足。

## 5. 当前结果不是完整市场清单

七家交易所表示当前只读行情来源范围，不代表全部市场、全部交易对和全部辅助字段都可用。筛选结果、资产数量和路线数量会随来源和市场状态变化。

本仓库截图来自公开前端，用于说明页面区域和阅读方法。截图中的资产、报价、数量、账户额度和策略状态都可能变化；当前事实以官网实时页面为准。
