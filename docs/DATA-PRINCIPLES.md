# 怎样理解页面上的数据

[**查看当前数据状态 →**](https://51taoli.com/opportunities)

## 看来源和时间

报价、资金费、标记价、指数价、公告、冲提和借贷的更新节奏不同。读一条路线时，应同时看字段来源和更新时间。

## 看资产是否可比

同名 ticker、相近价格或相同计价币，不一定表示同一资产。跨市场比较还需要核对产品类型、网络或合约地址、发行人、正式代码和单位等信息。

## 理解「暂无」

来源未提供、报价过期、身份未确认、单位不可比或历史尚未积累时，页面会显示「暂无」。

## 理解覆盖范围

七所交易所表示当前只读行情范围，不表示所有交易对、所有市场类型和所有辅助数据都可用。实际覆盖以官网当时显示为准。
