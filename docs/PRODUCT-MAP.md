| 页面 | 主要研究问题 | 页面必须保持的边界 |
| --- | --- | --- |
| **套利机会** `/opportunities` | 当前有哪些方向性 FF / SF / FS 市场观察？ | 正开差不是可执行利润；真实空状态不填充。 |
| **交易** `/trade` | 如何按资产、TradFi 分类、路线与交易所筛选？ | TradFi 产品目录与理论路线分开；同 ticker 不自动合并。 |
| **资金费** | 原始费率、原始周期与已结算记录是什么？ | 不将不同周期硬归一化为同一交易所事实；估算不等于预测。 |
| **指数观察** `/indices` | 同币种跨所或双币种的指数/标记价/资金费如何比较？ | 当前快照与闭合历史分开；缺失点不插值、不跨空值连线。 |
| **公告** `/announcements` | 有哪些可验证的官方公告或市场状态？ | 市场状态不冒充公告原文；无官方来源不伪造。 |
| **冲提** `/deposit-withdraw` | 某资产在某交易所/网络的充值、提现状态如何？ | 状态、费用、限额与时间必须来自同一 canonical 事实。 |
| **借贷** `/lending` | 借入/出借利率、额度和适用范围是什么？ | 公共数据不能写成“你的可借额度”；缺失不填 0。 |
| **策略** `/playbook` | 精选策略的状态、版本、规则和当前真实机会是什么？ | 路线类型不等于策略；观察中策略不能被描述为已开放订阅。 |
| **账户 / 订阅** | 我的权限、授权记录、策略订阅和通知渠道是什么？ | 登录不是交易所授权；页面权限和 API 权限必须一致。 |

## 统一体验原则

- **同一事实，同一口径**：首页弹窗与一级页面不能改变记录、单位、时间或来源状态；
- **桌面与移动端一致**：桌面适合高密度表格，移动端使用单焦点卡片，但不能隐藏关键未知或风险状态；
- **数据状态先于视觉完整感**：来源不可用或条件不满足时，保留明确空状态，不用示意行“填满”页面。
