# 产品页面地图

[**从机会总览开始 →**](https://51taoli.com/opportunities)

![51taoli 当前页面地图](../assets/product-map.svg)

| 页面 | 地址 | 主要用途 |
| --- | --- | --- |
| 机会总览 | `/opportunities` | 按资产、类别和七类路线发现当前研究对象 |
| 交易看板 | `/trade` | 按路线和交易所筛选，横向比较报价、开差、清差、资金费和辅助字段 |
| 资金费 | `/opportunities?tab=funding` | 查看费率、结算周期与资金费相关信息 |
| 公告 | `/announcements` | 查看交易所官方公告和市场事件 |
| 充提 | `/deposit-withdraw` | 核对资产与网络的充值、提现状态 |
| 借贷 | `/lending` | 核对借入 / 出借利率、额度与期限 |
| 指数 | `/indices` | 查看套利时点、指数证据和双币种相对关系 |
| 监控 | `/monitor` | 管理七类提醒、未读信息和监控状态 |
| 策略 | `/playbook` | 浏览 S01–S50 策略目录、规则、状态和真实样本 |
| 订阅 | `/subscription` | 查看当前版本、页面权限和额度 |
| 推广 | `/promote` | 查看推广入口与相关状态 |
| 账户 | `/account` | 管理账户和飞书通知地址 |
| 登录 | `/login` | 通过 Google 登录 51taoli |

页面是否可访问、可用额度和订阅价格以当前账户与官网显示为准。

## 常用跳转

- 看到路线后，先去 **交易看板**核对两条腿和辅助字段；
- 涉及衍生品时，去 **资金费**核对费率与周期；
- 涉及现货做空或资产周转时，去 **借贷**和**充提**核对条件；
- 想把条件持续盯住，进入 **监控**；
- 想按一套规则观察市场，进入 **策略**。
