# 官网页面地图

[**从“套利机会”开始 →**](https://51taoli.com/opportunities)

![从套利机会进入交易、资金费、指数、策略、辅助信息和账户页面的地图](../assets/product-map.svg)

| 页面 | 适合查看什么 |
| --- | --- |
| **套利机会** `/opportunities` | FF / SF / FS 路线和当前市场观察 |
| **交易** `/trade` | 按资产、类别、路线和交易所筛选 |
| **资金费** | 原始费率、周期和已结算记录 |
| **指数** `/indices` | 指数价、标记价、资金费和跨市场比较 |
| **公告** `/announcements` | 官方公告和市场状态 |
| **冲提** `/deposit-withdraw` | 资产和网络的充值、提现状态 |
| **借贷** `/lending` | 借入/出借利率、额度和适用范围 |
| **策略** `/playbook` | 策略规则、状态和当前机会 |
| **账户 / 订阅** | 登录、权限、订阅和通知设置 |
