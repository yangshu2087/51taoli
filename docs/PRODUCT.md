## 它不是交易机器人

如果你想找的是一个能连接交易所账户、自动下单、跟单或托管资金的工具，51taoli 目前不是。

它是一个**只读的跨市场套利情报平台**：读取已验证范围内的市场事实，整理成能被追问和复核的路线观察。它不替你交易，也不会要求你的交易所 API Key、余额或仓位。

## 为什么要多看一眼？

跨市场研究最容易在看起来“很简单”的地方翻车：

- 看到了最后成交价，却把它当成自己能成交的价格；
- 两边都叫同一个 ticker，就默认它们是一种资产；
- 看见正开差，就跳到“能赚钱”的结论；
- 数据没拿到，就用旧值、默认值或模拟值把页面填满。

51taoli 不解决每一个执行问题，但会把这些问题留在你眼前：**市场事实先摆清楚；证明不了的地方，就不要假装已经证明。**

## 你在产品里会走过五层

### 1. 先看市场当时给出了什么

行情买一/卖一、资金费、标记价、指数价、原生溢价、产品目录和辅助情报，各自保留来源和时间。一个字段更新，不代表其他字段也更新了。

### 2. 再看两条腿能组成什么路线

FF、SF、FS 是三种市场结构。页面把方向性 BBO、开差和退出方向拆开写，让你看见“多哪边、空哪边、理论差在哪里”。路线是观察方式，不是交易建议。

### 3. 然后问：两边真能比吗？

跨所资产要看网络、合约地址、发行人、正式代码、单位或其他官方证据。名字一样、价格接近、计价币一样，都还不够。

### 4. 需要时再补上下文

首页、交易、资金费、指数、公告、冲提、借贷和产品目录回答的是不同问题。它们互相补充，但不会把不同来源的数据硬拼成一个结论。

### 5. 最后才是策略和账户

策略有自己的版本、状态、规则、观察数据和权限。订阅或账号权限不会改变底层市场事实，也不授予交易执行能力。
