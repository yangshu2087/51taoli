# 51taoli 是什么？

[**打开官网，查看当前路线 →**](https://51taoli.com/opportunities)

51taoli 是一个只读的跨市场套利情报平台。它帮助你把分散的市场信息放在同一条研究路径里：两条腿分别是什么、报价方向怎样、资金费和其他条件是否值得继续看。

## 适合谁使用

- 想比较不同交易所、现货与合约市场的人；
- 想先做研究，再决定是否需要进一步核对执行条件的人；
- 需要同时查看行情、资金费、指数、公告、冲提、借贷和策略信息的人。

## 产品里有什么

| 入口 | 用途 |
| --- | --- |
| 套利机会 | 查看 FF / SF / FS 路线和当前市场观察 |
| 交易 | 按资产、类别、交易所和路线筛选 |
| 资金费、指数 | 查看原始费率、周期、价格和相关市场信息 |
| 公告、冲提、借贷 | 补充影响路线判断的公开事实 |
| 策略、订阅 | 查看策略规则、状态和个人可用权限 |

## 使用边界

51taoli 不代替用户下单，也不要求连接交易所账户或提供交易所 API Key。页面展示的是研究信息；是否执行以及如何执行，由用户自行判断。
