## 一句话说明

51taoli 将分散在不同交易所、不同市场类型中的市场事实，整理成可追溯的跨市场套利观察；它帮助用户研究机会，但不替用户交易。

## 为什么需要它

跨市场研究最容易出现四类错误：

1. 把最后成交价、标记价或中间价误当成可入场价格；
2. 把同名 ticker 直接当成同一资产；
3. 把理论开差直接当成可成交利润；
4. 在数据缺失时用默认值、旧值或模拟值掩盖问题。

51taoli 的设计目标是隔离这些错误：**先展示市场事实，再展示在明确假设下形成的理论观察；不能证明的部分保持未知。**

## 产品由五层组成

### 1. 市场事实层

读取已验证范围内的行情买一/卖一、资金费、标记价、指数价、原生溢价、产品目录和辅助情报。每类事实保留自己的来源与时间，不能用其中一个字段的更新时间覆盖另一个字段。

### 2. 路线观察层

以真实方向性 BBO 构成 FF、SF、FS 路线，并把开差和退出成本分开表达。路线是市场结构分类，不是策略，也不是交易建议。

### 3. 身份与质量层

跨所资产需要由规范网络、合约地址、发行人、正式代码、单位或其他官方证据支持。相同 ticker、价格接近或相同计价币，都不是跨所资产等价的充分条件。

### 4. 研究工具层

首页、交易、资金费、指数、单资产详情、公告、冲提和借贷页面各自回答一个研究问题；同名事实在不同页面必须保持同一口径。

### 5. 策略与账户层

精选策略具有独立身份、版本、状态、规则、观察数据和权限。策略订阅、账号权限与通知渠道都不改变底层市场事实，也不授权交易执行。

## 当前范围

- **交易所**：Binance、OKX、Bybit、Bitget、Gate、Hyperliquid、Aster；
- **资产层级**：加密货币与 TradFi；TradFi 按股票、大宗、金属、指数、外汇、债券等官方类别分层；
- **路线**：FF / SF / FS 按各自数据与语义证据独立验收；
- **辅助情报**：公告、冲提、借贷只在每项官方能力已经验证时展示；
- **研究记录**：当前值、闭合历史、官方已结算资金费和平台策略表现使用不同数据语义，不能混为同一种“历史”。

## 当前不做什么

51taoli 当前不下单、不跟单、不管理用户资金，不接入用户交易所账户、持仓、余额或 API Key；也不把理论观察写成收益承诺、可成交利润或未来预测。

未来若出现账户连接或交易能力，必须有独立的产品、安全、权限、撤销和真实验收合同。当前没有此类公开能力。
