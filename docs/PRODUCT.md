# 产品介绍

## 一句话说明

51taoli 把分散在不同交易所、不同市场类型中的市场事实，整理成可追溯的跨市场套利观察；它帮助用户研究机会，但不替用户交易。

## 解决什么问题

跨市场研究最容易出现四类错误：

1. 把最后成交价、标记价或中间价误当成可入场价格；
2. 把同名 ticker 直接当成同一资产；
3. 把理论开差直接当成可成交利润；
4. 在数据缺失时用默认值、旧值或模拟值掩盖问题。

51taoli 的设计目标是把这些错误显式隔离：先展示市场事实，再展示在明确假设下形成的理论观察；不能证明的部分保持未知。

## 产品包含什么

### 市场机会

- 以真实方向性买一/卖一构成 FF、SF、FS 路线；
- 展示开差、清差、资金费、指数/标记价、来源时间和数据状态；
- 对缺少深度、实际费率、退出盘口或借贷事实的路线，不把理论价差升级为净收益。

### 市场情报

- 七所只读行情范围内的加密货币市场事实；
- TradFi 官方产品目录与经过严格身份、单位和 BBO 条件后形成的理论观察；
- 按官方能力提供的公告、充提、借贷与指数信息。

### 策略与研究

平台策略是独立、带版本、带生命周期的筛选和通知规则。策略不等于 FF/SF/FS 路线，不授权交易执行，也不应被理解为收益承诺。

## 当前不做什么

- 不下单、不跟单、不管理用户资金；
- 不接入用户交易所账户、持仓、余额或 API Key；
- 不把理论观察写成交易建议、可成交收益或保证回报；
- 不因数据不完整而伪造路线、价格或历史。

## 使用前应知道

任何真实交易决策仍需由用户自行完成和判断。盘口深度、手续费、滑点、资金费、借贷成本、额度、仓位限制、市场停牌与产品规则都会改变实际结果。

阅读 [核心概念](CONCEPTS.md) 和 [数据原则](DATA-PRINCIPLES.md)，可以帮助你正确理解页面中的数字与空状态。
