# 51taoli 是什么？

[**打开官网，查看当前路线 →**](https://51taoli.com/opportunities)

51taoli 将跨交易所、跨市场的信息放在一起，帮助你从一条路线开始：两条腿分别是什么、报价方向怎样、还可以去哪里补充市场信息。

![读一条路线时的五个重点：多腿 ask、空腿 bid、开差、资金费、时间与身份](../assets/read-route.svg)

## 适合谁使用

- 想比较不同交易所、现货与合约市场的人；
- 想先做研究，再决定下一步看什么的人；
- 需要同时查看行情、资金费、指数、公告、冲提、借贷和策略信息的人。

## 产品里有什么

| 入口 | 用途 |
| --- | --- |
| 套利机会 | 查看 FF / SF / FS 路线和当前市场观察 |
| 交易 | 按资产、类别、交易所和路线筛选 |
| 资金费、指数 | 查看费率、周期、价格和相关市场信息 |
| 公告、冲提、借贷 | 补充影响路线判断的公开信息 |
| 策略、订阅 | 查看策略规则、状态和个人可用权限 |
