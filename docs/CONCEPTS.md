## 路线类型

| 类型 | 含义 |
| --- | --- |
| **FF** | 合约 / 永续与合约 / 永续之间的跨所路线 |
| **SF** | 现货多、合约 / 永续空 |
| **FS** | 合约 / 永续多、现货空，通常还需要核对借贷条件 |

路线是市场结构的分类；策略则是附加在路线之上的筛选或通知规则。

## 开差与清差

- **开差**：按当前报价进入时，两条腿之间的理论距离；
- **清差**：按相反方向退出时，两条腿之间的理论成本；
- 做多腿看 `ask`，做空腿看 `bid`；退出时方向相反。

```text
开差(%) = 200 × (做空腿 bid − 做多腿 ask) ÷ (做空腿 bid + 做多腿 ask)
```

## 三种不同的结果

| 名称 | 含义 |
| --- | --- |
| 理论价差 | 由最优买一/卖一得到的价差 |
| 可执行差价 | 考虑指定金额和盘口深度后的估算 |
| 净边际 | 进一步考虑实际费率、滑点、借贷和退出成本后的结果 |

## 其他常见字段

- **资金费**：交易所定义的费率和结算周期；
- **指数偏离**：`(标记价格 − 指数价格) ÷ 指数价格`；
- **原生溢价**：交易所明确提供的原生字段或序列。

## 「暂无」

表示当前没有足够的数据、来源或可比条件来给出结论。它不等于 0。
