# 核心概念

[**带着这些概念看官网 →**](https://51taoli.com/opportunities)

## S、F、T 分别是什么

- `S`：加密货币现货（Spot）
- `F`：期货、永续等衍生品（Futures / Derivatives）
- `T`：TradFi/RWA 产品

路线代码由两位字母组成：**第一位是做多腿，第二位是做空腿**。

![FF、SF、FS、SS、TF、FT、TT 七类路线](../assets/route-types.svg)

| 路线 | 做多腿 | 做空腿 | 常见研究场景 |
| --- | --- | --- | --- |
| `FF` | 衍生品 | 衍生品 | 不同衍生品市场的价差 |
| `SF` | 加密现货 | 衍生品 | 正向期现 / 跨所基差 |
| `FS` | 衍生品 | 加密现货 | 反向期现，并核对现货可借条件 |
| `SS` | 加密现货 | 加密现货 | 不同现货市场的价差 |
| `TF` | TradFi/RWA | 衍生品 | 传统市场产品多、衍生品空 |
| `FT` | 衍生品 | TradFi/RWA | 衍生品多、传统市场产品空 |
| `TT` | TradFi/RWA | TradFi/RWA | 两个 TradFi/RWA 市场之间 |

## 开差

进入路线时：

- 做多腿使用当前可买入的 `ask`；
- 做空腿使用当前可卖出的 `bid`。

```text
开差(%) = 200 × (做空腿 bid − 做多腿 ask)
          ÷ (做空腿 bid + 做多腿 ask)
```

这是方向正确的**理论开仓价差**，还没有包含你的实际成交量、滑点和全部费用。

## 清差

退出路线时方向相反：

- 原做多腿用 `bid` 卖出；
- 原做空腿用 `ask` 买回。

```text
清差(%) = 200 × (原做空腿回补 ask − 原做多腿退出 bid)
          ÷ (原做空腿回补 ask + 原做多腿退出 bid)
```

页面用正数成本表达清差。它来自同一资产、同一两腿、同一真实快照中的退出 BBO；缺少任一退出报价时显示「暂无」。

因此，开差和清差不能互相替代，也不能只看其中一个数字。

## 三层结果不要混在一起

| 层级 | 回答什么 |
| --- | --- |
| 理论价差 | 最优方向报价之间有多大距离 |
| 可执行价差 | 加上金额、盘口深度、滑点和显性费用后，还剩多少 |
| 风险调整净边际 | 再考虑资金费、借贷、退出、身份可比性和市场变化后的研究结果 |

51taoli 页面上的理论数值只是研究起点，不是收益。

## 常见字段

- **净资金费**：按两条腿方向合并后的资金费影响；不同结算周期需要分别理解。
- **指数偏离**：标记价相对指数价的偏离，通常写作 `(标记价 − 指数价) ÷ 指数价`。
- **盘口深度**：给定金额下实际可能成交的价格和数量，不等于最优一档报价。
- **借贷**：现货做空或资产周转时可能需要核对的利率、额度与期限。
- **产品身份**：ticker 相同不代表资产、合约、发行人或单位相同。
- **暂无**：当前来源没有返回、数据已过期、身份未确认或条件不可比。
