# 51taoli 公开资料索引

本仓库面向用户、研究者和公开协作者；不包含生产源码、访问凭证或内部部署资料。

## 建议阅读顺序

1. [产品介绍](PRODUCT.md)：定位、范围、核心能力与不做什么；
2. [研究路径](USE-51TAOLI.md)：第一次如何从首页读一条路线；
3. [产品页面地图](PRODUCT-MAP.md)：官网各页面的用途和边界；
4. [核心概念](CONCEPTS.md)：FF / SF / FS、开差、清差、资金费和指数；
5. [数据原则](DATA-PRINCIPLES.md)：来源、身份、时间、缺失与验证规则；
6. [FAQ](FAQ.md)：常见产品、策略、账号和社群问题；
7. [安全说明](../SECURITY.md)：哪些信息绝不应提交。

## 文档使用边界

- 本仓库只解释公开产品定位、用户概念、数据原则和官方支持入口；
- 实时行情、功能开放、套餐状态、覆盖和服务可用性，以官网当时展示、来源状态和实际验证为准；
- 未经核验的功能、收益、恢复状态或未来计划不会被表述为既成事实；
- 无数据时，「暂无」是正确答案，不会用示意数据替代。
