# 51taoli 公开资料索引

本仓库面向用户和公开协作者，不包含生产源码、访问凭证或内部部署资料。

## 阅读路径

1. **第一次了解项目**：阅读 [产品介绍](PRODUCT.md)；
2. **理解页面上的数字**：阅读 [核心概念](CONCEPTS.md)；
3. **了解数据边界**：阅读 [数据原则](DATA-PRINCIPLES.md)；
4. **解决常见使用问题**：阅读 [FAQ](FAQ.md)；
5. **提交可复现反馈**：使用 [数据问题模板](../.github/ISSUE_TEMPLATE/data-report.md) 或 [一般问题模板](../.github/ISSUE_TEMPLATE/question.md)。

## 公开资料的边界

- 本仓库只解释已公开的产品定位、用户概念、数据原则和官方支持入口；
- 任何实时行情、覆盖、服务可用性、套餐状态或功能开关，以官网当时展示与来源状态为准；
- 未经核验的功能、收益、恢复状态或未来计划不会在这里被表述为既成事实；
- 无数据时，“暂无”是正确答案，不会使用示意数据替代。
